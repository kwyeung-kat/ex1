為什麼在 GitHub Pages 看不到學生 iPad 的作答？

因為 GitHub Pages 是純靜態網頁空間，需要貼入一組免費的 Firebase 專案設定（firebaseConfig） 才能跨裝置即時傳輸資料。

設定完成後，系統會自動產生一條帶有同步金鑰的專屬網址，學生掃描該網址的 QR Code 作答，您的教師電腦就能秒速同步看到 5 組結果！
